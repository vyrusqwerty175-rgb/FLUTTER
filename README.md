# ProConnect

A Flutter marketplace app for finding and booking trusted local professionals. Browse service categories, search nearby providers, save favorites, and request a booking.

## Run locally

1. Install [Flutter](https://docs.flutter.dev/get-started/install).
2. From the project root, run `flutter pub get`.
3. Launch with `flutter run` on an emulator or connected device.

The starter app includes a responsive marketplace home screen, category filtering, provider search, favorites, professional detail sheets, booking requests, and bookings/profile navigation.
